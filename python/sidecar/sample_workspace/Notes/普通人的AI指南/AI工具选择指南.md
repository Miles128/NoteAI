AI 工具现在大致分成三类。你不需要全都会用，关键是知道**手头这件事**该掏哪个。

---

## 三类工具，一句话区分

- **对话式 AI App**（豆包、ChatGPT、DeepSeek、Kimi 等）：你问它答，像身边坐了个参谋。适合**想问题、出主意、写草稿**。
- **专用应用 + AI**（WPS AI、Canva、剪映、Notion AI 等）：专业工具里加了 AI 功能，像给工匠升级了工具箱。适合**做具体格式的成品**——文档、表格、PPT、图片、视频。
- **通用 Agent 平台**（WorkBuddy、TRAE Work、Qoder Work 等）：AI 自己规划步骤、操作工具、交付结果，像雇了个实习生。适合**多步骤、跨文件的自动化任务**。

## 怎么选：看你的任务长什么样

不用记分类，问自己一个问题就够了：**这件事的核心动作是什么？**

### 情况一：我要的是"想法、建议、文字内容" → 对话式 AI

你需要的本质上是一个能聊天的聪明人。

**典型场景：**

- "解释一下体检报告里的'糖化血红蛋白 6.8%'是什么意思"
- "我在纠结要不要换工作，帮我列一下利弊"
- "帮我写一封给房东的信，说明空调坏了需要维修"
- "对比一下等额本金和等额本息的区别"
- "帮我润色这段自我介绍，让它更适合面试"
- "用大白话解释一下什么是区块链"
- "帮我出 5 个周末带孩子在杭州玩的方案"

**为什么不需要别的：** 这些任务从头到尾都是"你说需求，它给内容"。你拿到内容后自己决定怎么用。不需要 AI 操作文件，不需要它帮你排版，不需要它自动执行什么。

**对话 AI 之间的差异：** 不同 App 的模型能力有差异，但对普通人来说差别不大。选一个你用着顺手、打开方便的就行。如果你有深度推理需求（比如复杂的数学题或代码），可以试试 DeepSeek 或 ChatGPT；如果就是日常问答写作，豆包、Kimi、通义千问都够用。

### 情况二：我要的是"特定格式的成品" → 专用应用

你需要的是一个带 AI 功能的专业工具。

**典型场景：**

| 你要什么 | 用什么 | AI 帮你做什么 |
|---------|--------|-------------|
| 一份排版好的 Word 报告 | **WPS AI / Word Copilot** | 直接在文档里生成带格式的内容、自动排版、调整样式 |
| 一份有数据透视表的 Excel | **WPS 表格 / Excel Copilot** | 直接在表格里写公式、做透视表、生成图表 |
| 一份 PPT 演示稿 | **WPS 演示 / Gamma / 美图 AI PPT** | 输入主题自动生成幻灯片，支持模板和动画 |
| 一张社交媒体配图 | **Canva / 美图秀秀** | AI 生成或编辑图片，直接适配平台尺寸 |
| 一段短视频 | **剪映 / CapCut** | AI 自动加字幕、剪辑、配乐、生成口播视频 |
| 一篇排版精美的公众号文章 | **135 编辑器 / 秀米 + AI** | 自动套模板排版，生成可直接发布的格式 |
| 一份思维导图 | **XMind AI / 幕布** | 输入主题自动生成结构化思维导图 |
| 一个网站或落地页 | **Framer / Wix AI** | 描述需求直接生成可上线的网页 |

**为什么不用对话 AI：** 你可以让 ChatGPT 帮你写 PPT 大纲，但它没法直接生成 PPT 文件。你可以让它写表格公式，但它没法直接在你的 Excel 里执行。专用应用的 AI 能**直接在你的工作成果里操作**，省去了"复制粘贴→手动调格式"的过程。

**为什么不用 Agent 平台：** 杀鸡用牛刀。做一份 PPT、修一张图、剪一个视频，专用应用做得更快、效果更可控。Agent 平台的优势在多步骤自动化，单一格式的成品用专用工具更直接。

### 情况三：我要的是"AI 替我完成一系列操作" → Agent 平台

你需要的是一个能自己干活的人。

**典型场景：**

- "把桌面上 30 份 PDF 合同里的关键条款（甲方、乙方、金额、期限）全部提取出来，汇总到一个 Excel 表格里"
- "每周一早上自动抓取上周的新闻报道，整理成一份简报，发到我的邮箱"
- "读取这份 Excel 里的销售数据，做交叉分析，生成带图表的季度报告"
- "把 5 篇英文论文翻译成中文，保留术语原文，输出为 5 个 Word 文档"
- "整理我的下载文件夹，按文件类型分类，超过 30 天的临时文件清理掉"

**为什么不用对话 AI：** 对话 AI 能帮你分析一份合同，但不能批量处理 30 份。它能给你写报告的思路，但不能自己去读数据文件然后生成图表。这些任务需要 AI **操作你电脑上的文件、调用工具、按步骤自动执行**。

**为什么不用专用应用：** WPS 能帮你做一份漂亮的 Excel，但不能自动从 30 份 PDF 里提取数据填进去。剪映能帮你剪视频，但不能自动从文件夹里找出所有视频素材并按日期排列。专用应用擅长做单个精品，Agent 平台擅长批量自动化。

## 一个场景可能需要多种工具

现实中，很多任务是混合的。比如"写一份季度工作汇报"：

- **对话 AI** 帮你理清思路、拟定大纲、润色文字
- **WPS AI** 帮你把内容排成正式的 Word 文档
- **Agent 平台** 帮你从邮件和项目文档里自动汇总这季度的工作成果

这种情况下，合理的做法是**先用 Agent 收集素材，再用对话 AI 打磨内容，最后用 WPS 出成品**。但如果你嫌麻烦，也可以全程只用一个工具——效率低一点，但也能完成。

## 简单决策树

```
你要做的事是什么？
│
├── 要的是想法、建议、解释、文字内容
│   └── → 打开你常用的对话 AI App，直接问
│
├── 要的是特定格式的成品（文档/表格/PPT/图片/视频）
│   └── → 打开对应的专用应用，用里面的 AI 功能
│
├── 要的是 AI 帮你自动完成一系列操作
│   ├── 涉及大量文件批量处理 → Agent 平台
│   ├── 涉及定时/周期性任务 → Agent 平台
│   └── 涉及跨多个系统操作 → Agent 平台
│
└── 不确定
    └── → 先用对话 AI 试试。如果它搞不定，再考虑换工具
```

## Agent 平台的个人应用场景：不只是办公

上面说的"批量处理文件、跨系统操作"听起来很办公。但 Agent 平台对个人也越来越实用了——很多日常生活中反复折腾的事，Agent 能一次帮你理顺。下面列几个真正有价值的个人场景，以及大致怎么实现。

### 场景一：个人知识库搭建

**痛点：** 你收藏了几百篇文章、截图、PDF、笔记，散落在微信收藏、浏览器书签、本地文件夹里。想找某篇的时候永远找不到。

**Agent 能做什么：** 把散落的资料全部读进来，提取关键信息，自动打标签分类，建一个可以对话检索的知识库。

**大致实现方案：**

1. 把你收藏的文章、笔记、PDF 放到一个文件夹
2. 让 Agent 逐份读取，为每份内容提取：标题、核心观点、关键词、分类标签
3. 汇总成一个 Excel 或 Markdown 索引文件，按主题分类
4. 以后想找资料时直接问 Agent："我之前收藏过一篇讲间歇性断食的文章，帮我找出来"

**用到的 Agent 能力：** 批量文件读取、内容提取与摘要、自动分类打标、知识库检索。

**推荐平台：** Qoder Work（本地文件操作方便，支持知识库 Skill）或 WorkBuddy（文件管理能力强）。

### 场景二：待办事项智能整理

**痛点：** 你的待办事项分散在微信聊天记录、邮件、备忘录、便签纸上。有的事忘了做，有的事记了两遍，有的事其实已经做了但没划掉。

**Agent 能做什么：** 从多个来源汇总待办事项，去重、分类、排优先级，生成一份清爽的任务清单。

**大致实现方案：**

1. 导出或截图你的微信聊天中提到的事项、邮件中的 action items、备忘录里的清单
2. 让 Agent 读取所有来源，提取每一条待办事项
3. 去重合并，按"紧急/重要"矩阵分类，标注来源（谁让你做的、什么时候提到的）
4. 输出一份整理好的任务清单（Excel 或 Markdown）
5. 进阶：设置定时任务，每周一早上自动汇总上周未完成的事项 + 本周新增事项

**用到的 Agent 能力：** 多来源信息提取、去重合并、分类排序、定时任务自动化。

**推荐平台：** Qoder Work（定时任务 + 文件操作）或 WorkBuddy（邮件和文件集成好）。

### 场景三：简历和面试准备

**痛点：** 每次投简历都要针对 JD 微调，面试前要准备自我介绍、常见问题答案、了解公司背景。整个过程繁琐且容易遗漏。

**Agent 能做什么：** 分析 JD 匹配你的经历，生成定制化简历，模拟面试问答，调研目标公司。

**大致实现方案：**

1. 准备一份你的"经历素材库"——把所有工作经历、项目经验、技能证书写在一个 Word 文档里（不用在意格式，把所有东西都放进去）
2. 每次投简历时，把目标岗位的 JD 和经历素材库一起交给 Agent，让它：
   - 分析 JD 的核心要求
   - 从你的经历库里挑最匹配的部分
   - 生成一份针对性简历（Word 格式）
   - 附上一段"这个岗位我为什么要投"的求职信草稿
3. 面试前让 Agent：
   - 搜索目标公司最近的新闻、产品动态、融资信息
   - 生成一份公司简报
   - 根据 JD 模拟面试官可能问的问题，帮你准备回答

**用到的 Agent 能力：** 联网搜索、文档分析与生成、角色扮演模拟、多文件操作。

**推荐平台：** 三个平台都能做。TRAE Work 搜网能力强，Qoder Work 文件操作方便。

### 场景四：自媒体运营与信息爬取

**痛点：** 做自媒体需要追热点、分析爆款、积累素材、定时发布。每天手动刷平台、收藏内容、整理选题，光准备工作就花掉大半时间。

**Agent 能做什么：** 自动抓取行业热点和竞品信息，分析爆款规律，帮你积累素材库，辅助内容生产。

**大致实现方案：**

1. **热点监控：** 让 Agent 每天定时搜索你所在领域的关键词（如"育儿""理财""穿搭"），抓取各平台的热门话题和爆款标题，生成一份"今日热点速览"
2. **爆款分析：** 把一周内收集到的爆款文章/视频标题交给 Agent 分析，找出共性规律——什么类型的标题点击率高、什么话题互动多
3. **素材库积累：** 每次看到好素材（图片、金句、案例），扔进一个文件夹。定期让 Agent 整理归类，打上标签（"适合开头引用""适合做对比""适合做案例"）
4. **选题辅助：** 结合热点和你的素材库，让 Agent 推荐 5 个本周选题，每个附上切入角度和参考素材
5. **竞品监控：** 设定 3-5 个竞品账号，Agent 每天自动抓取他们的新内容，汇总成"竞品动态日报"

**用到的 Agent 能力：** 联网搜索与爬取、定时任务、批量内容分析、分类打标、内容生成。

**推荐平台：** Qoder Work（定时任务 + 搜索能力 + Skills 生态）最适合。WorkBuddy 浏览器自动化也可以用于信息爬取。

### 场景五：学习与读书笔记体系

**痛点：** 看了很多书、听了很多课、刷了很多教程，但笔记分散在各种 App 里，过几个月就忘了学过什么。

**大致实现方案：**

1. 把所有读书笔记（微信读书划线、Kindle 标注、手动笔记、课程截图）汇总到一个文件夹
2. 让 Agent 逐份提取，按书籍/课程整理，提取核心观点、金句、你的批注
3. 为每本书生成一页"精华卡片"（核心论点 + 3 个关键概念 + 你的感悟 + 行动建议）
4. 建一个跨书籍的主题索引——比如搜"习惯养成"，能找到所有相关书籍里的相关段落
5. 定期让 Agent 做"知识回顾"：随机抽取 3 个月前的笔记，生成一份"你可能忘了的好东西"回顾

**用到的 Agent 能力：** 批量文件处理、内容提取与摘要、跨文档关联、定时任务。

### 场景六：家庭财务记账与分析

**痛点：** 想搞清楚家里钱花到哪了，但记账 App 太琐碎，银行账单下载后懒得看。

**大致实现方案：**

1. 下载近 3-6 个月的银行/支付宝/微信账单（CSV 或 Excel 格式）
2. 让 Agent 读取所有账单，自动分类（餐饮/交通/购物/教育/医疗/娱乐等）
3. 生成一份支出分析报告：每月总支出趋势、各品类占比饼图、环比变化
4. 标注异常消费（突然大额支出、重复扣款等）
5. 进阶：设置月度定时任务，每月 1 号自动生成上月的支出报告

**用到的 Agent 能力：** 多文件数据读取、自动分类、数据分析与可视化、定时任务。

### 场景七：购物比价与决策

**痛点：** 买个大件要对比多个平台的价格、参数、评价，来回切换浏览器标签页很烦。

**大致实现方案：**

1. 告诉 Agent 你想买什么（如"3000 元左右的扫地机器人"）
2. Agent 搜索多个平台的产品信息，提取价格、核心参数、用户评价关键词
3. 生成一份对比表格，标注各产品的优缺点
4. 附上购买建议：根据你的需求（如家里有宠物、需要拖地功能）推荐最适合的一款

**用到的 Agent 能力：** 联网搜索、信息提取与结构化、对比分析。

## 给普通人的务实建议

**先精通一个对话 AI。** 80% 的即时需求，一个对话 AI App 就能搞定。把提示词技巧练好（说清楚需求、给够背景、多轮迭代），比学一堆工具更有用。

**遇到格式需求加专用应用。** 当你发现"ChatGPT 给的内容我还得手动搬到 Word 里调格式"的时候，试试 WPS AI 这类工具。专用应用的价值在于省掉"从文本到成品"的手工环节。

**日常生活和工作值得认真试试 Agent 平台。** 上面这些场景——知识库、待办整理、简历面试、自媒体运营、读书笔记、家庭财务——都不是"办公场景"，而是普通人的日常。Agent 平台的价值不只是帮你批量处理文件，而是把那些"知道该做但一直没精力做"的事帮你做了。花一个下午装一个平台，挑一个最痛的场景跑通，你会发现回不去。

**工具之间不冲突。** 很多人同时用两三个：日常问答用豆包，正式文档用 WPS AI，知识管理和自动化用 Agent 平台。选你顺手的那套组合就行。
