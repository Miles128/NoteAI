## 学习建议

1. **从旗舰文档开始**：先读《普通人AI指南》建立整体认知
2. **边学边用**：每学一个工具，立刻动手试用
3. **不要贪多**：先精通2-3个工具，再扩展
4. **建立提示词库**：把好用的提示词保存下来
